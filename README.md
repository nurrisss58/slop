# NAir High

GitHub Pages-ready front-end prototype.

## Structure
All HTML, CSS, JS and image assets are in the repository root so the project works directly on GitHub Pages.

## Functional interactions
- Flight search passes route/date/passenger data to the results page.
- Flight selection passes the selected flight and price into booking.
- Destination filters work for Europe, Asia, Americas and Oceania.
- Destination cards open booking for the selected city.
- Login modal, mobile navigation, FAQ and forms are interactive demo flows.
- Team overview includes two individual profile pages.

This is a front-end prototype; payment, real authentication and airline reservation APIs are not connected.
